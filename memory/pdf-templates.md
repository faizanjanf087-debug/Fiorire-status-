# PDF order summary

- Make HTML in scratchpad, render with Playwright (A4, printBackground), send with SendUserFile.
- Sections: logo, ORDER SUMMARY, badge (PAID IN FULL or ADVANCE RECEIVED), customer details, order details, totals, payment box.
- Show advance date, bank name, STAN reference. Do not show full account numbers.
- Examples: Syeda (SYD-17NOV-2026), Areeba (ARB-12NOV-2026), Hamza (HMZ-18NOV-2026).
