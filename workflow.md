# Workflow (follow on EVERY screenshot or command)

1. Pull the repo first: `git pull --rebase origin main`.
2. Read in this order, before any thinking:
   a. rules.md (owner rules)
   b. cloud.md (customer table, prices, pending decisions)
   c. history.md (latest chat log and decisions, newest first)
   d. fiorire-26-27-28-all-in-one.md (only if the customer is not in cloud.md)
3. Read the full screenshot or message. Do not assume.
4. Find the customer in the table. Check: branch, welcome done, salam done, what we said last, what they asked, what is pending.
5. Check the owner's latest instruction in this chat.
6. Only now write the reply (copy box, Roman Urdu meaning below if English).
7. Update cloud.md (table and pending), history.md (new dated entry), and rules.md if a new owner rule came in.
8. Commit and push right away, then tell the owner what changed.
